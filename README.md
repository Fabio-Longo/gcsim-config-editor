# gcsim config editor

Полностью навайбкоженный GUI-редактор конфигов [gcsim](https://gcsim.app) для Genshin Impact: команда до 4 героев (созвездия, уровень, таланты, оружие, сеты и статы артефактов) и таймлайн ротации с drag & drop. Справа внизу — готовый конфиг (Copy / Download). Интерфейс на русском и английском (переключатель в шапке), поиск находит героев, оружие и сеты по имени на любом из языков gcsim: EN, RU, ZH, JA, KO, DE, ES. В ротацию можно вставить паузу «Ждать» на N секунд (в конфиге — `wait(кадры)`, 60 кадров = 1 с). Состояние сохраняется в `localStorage`.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:5173.

## Обновление данных после патча игры

```bash
npm run fetch-data
```

Скрипт `scripts/fetch-data.mjs` берёт ключи, имена, элементы и допустимые действия персонажей из репозитория gcsim, а иконки — с Enka CDN (сохраняются в WebP). Результат: `src/data/gamedata.json` и `public/img/**` (уже скачанные иконки не перекачиваются).


## Устройство

- `src/i18n.tsx` — строки интерфейса (en/ru) и переключение языка
- `src/rotation.ts` — дерево ротации (действия и блоки) и операции над ним
- `src/state.ts` — состояние (reducer) и сохранение в localStorage
- `src/config.ts` — генерация текста конфига gcsim
- `src/components/CharacterSlot.tsx` — карточка героя
- `src/components/Timeline.tsx` — редактор ротации: ленты, блоки, drag & drop (dnd-kit)
- `src/components/Picker.tsx` — модалка выбора с поиском и картинками

Статы артефактов вводятся одной суммой со всех 5 предметов (основные + доп., включая HP цветка и атаку пера); проценты — в процентах, в конфиг пишутся долями. У карточек Skill/Burst есть чекбокс «Пропустить, если на перезарядке» — в конфиге это `if .герой.skill.ready { ... }`.

### Блоки в ротации

Через «+» в любой ленте можно добавить не только действие или паузу, но и блок:

- **Блок действий** — группа карточек, которую можно двигать целиком (в конфиг пишется просто содержимое);
- **if / else** — условие пишется вручную в поле в заголовке блока (поле растёт по мере ввода), кнопки «+ else if» и «+ else» — в полоске под последней веткой, она «приоткрывает» следующий рельс и уезжает вниз при добавлении ветки;
- **while** — цикл с условием.

Блоки вкладываются друг в друга без ограничений; при наведении подсвечивается блок под курсором и всё, что в него вложено. Любую карточку или блок (за ⠿) можно перетащить в любую ленту, продублировать (⧉) или удалить (×). Пустое условие пишется как `0 # TODO: condition`, чтобы конфиг оставался валидным.
