# gcsim config editor

GUI-редактор конфигов [gcsim](https://gcsim.app) для Genshin Impact: команда до 4 героев (созвездия, уровень, таланты, оружие, сеты и статы артефактов) и таймлайн ротации с drag & drop. Справа внизу — готовый конфиг (Copy / Download). Интерфейс на русском и английском (переключатель в шапке), поиск находит героев, оружие и сеты по имени на любом из языков gcsim: EN, RU, ZH, JA, KO, DE, ES. В ротацию можно вставить паузу «Ждать» на N секунд (в конфиге — `wait(кадры)`, 60 кадров = 1 с). Состояние сохраняется в `localStorage`.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:5173.

## Обновление данных после патча игры

```bash
npm run fetch-data
```

Скрипт `scripts/fetch-data.mjs` берёт ключи, имена, элементы и допустимые действия персонажей из репозитория gcsim, а иконки — с Enka CDN. Результат: `src/data/gamedata.json` и `public/img/**` (уже скачанные иконки не перекачиваются).

## Устройство

- `src/i18n.tsx` — строки интерфейса (en/ru) и переключение языка
- `src/state.ts` — состояние (reducer) и сохранение в localStorage
- `src/config.ts` — генерация текста конфига gcsim
- `src/components/CharacterSlot.tsx` — карточка героя
- `src/components/Timeline.tsx` — ротация (dnd-kit)
- `src/components/Picker.tsx` — модалка выбора с поиском и картинками

Статы артефактов вводятся одной суммой со всех 5 предметов (основные + доп., включая HP цветка и атаку пера); проценты — в процентах, в конфиг пишутся долями. У карточек Skill/Burst есть чекбокс «Пропустить, если на перезарядке» — в конфиге это `if .герой.skill.ready { ... }`.
